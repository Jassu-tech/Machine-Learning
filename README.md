# 🚀 Machine Learning Portfolio

A collection of end-to-end Machine Learning projects covering Regression, Natural Language Processing (NLP), and Computer Vision.

---

## 🛠️ Projects Overview

### 1. 🏠 House Price Prediction
* **Type:** Regression / Tabular Data
* **Model:** Random Forest Regressor
* **Description:** Predicts housing market prices based on features like median income, house age, and room count using the California Housing dataset.
* **Notebook:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Jassu-tech/Machine-Learning/blob/main/01-house-price-prediction/notebooks/house_price_prediction.ipynb)

---

### 2. 📩 Spam SMS Classifier
* **Type:** Natural Language Processing (NLP) / Text Classification
* **Model:** TF-IDF Vectorizer + Multinomial Naive Bayes
* **Description:** Classifies incoming text messages as Spam or Ham (legitimate) based on keyword features.
* **Notebook:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Jassu-tech/Machine-Learning/blob/main/02-spam-sms-classifier/notebooks/spam_sms_classifier.ipynb)

---

### 3. 🔢 Handwritten Digit Recognizer
* **Type:** Computer Vision / Classification
* **Model:** Multi-Layer Perceptron (Neural Network)
* **Description:** Classifies 8x8 pixel images of handwritten digits (0–9) using pixel intensity normalization and neural networks.
* **Notebook:** [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Jassu-tech/Machine-Learning/blob/main/03-digit-recognizer/notebooks/digit_recognizer.ipynb)
